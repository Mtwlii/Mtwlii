## 🚀 Featured Projects

### 🛒 FreshCart — E-commerce web app
`Next.js` `TypeScript` `Tailwind CSS` `NextAuth`

- Sign up / login with NextAuth sessions and protected routes
- Browse by category and brand, search and filter products
- Cart, wishlist, checkout and order history
- Fully responsive, deployed on Vercel

[**Live demo**](https://e-commerce-jet-phi.vercel.app/) · [Source code](https://github.com/Mtwlii/E-Commerce)

### 🌐 SocialHub — Social media app
`React 19` `Vite` `TanStack Query` `React Hook Form` `Zod` `Framer Motion` `Tailwind CSS`

- Posts with image upload, preview and crop before publishing
- Follow system, bookmarks and user profiles
- Protected and guest-only routes, dark mode, toast notifications
- Server state with TanStack Query; forms validated with React Hook Form + Zod

[**Live demo**](https://socialhub-blond-delta.vercel.app/login) · [Source code](https://github.com/Mtwlii/social-app)

### 🔐 NGL App — Anonymous messaging REST API
`Node.js` `Express 5` `MongoDB` `Redis` `Zod` `JWT`

- **Architecture:** layered (routes → controllers → services → repositories) with DTOs
- **Auth:** email OTP verification, Google Sign-In, JWT in an `httpOnly` cookie, bcrypt password hashing
- **Security:** Zod validation on every request body and on environment variables at startup, rate limiting on login / OTP / anonymous messages, uploads verified by file signature (magic number)
- **Reliability:** Redis caching, idempotency keys, centralized error handling with correlation IDs, graceful shutdown

[Source code](https://github.com/Mtwlii/ngl-app) <!-- add: · [Live API](https://your-service.onrender.com) after deployment -->

- Dark, premium look with gold accents, refined over several redesign iterations
- Also designed branded content for the café, such as a holiday greeting card
